**设计讨论稿 · 尚未实现（业务方案）。**

这是提案，不承诺日期。

| 阶段 | 交付物 | 退出条件 |
| --- | --- | --- |
| 0：文档准备 | 本轮讨论稿、站点配置、构建与发布工作流 | 构建通过，草稿 PR 可审阅 |
| 1：需求确认 | 最小用户场景、范围、问题结论 | 相关参与者确认内容 |
| 2：设计确认 | 流程、边界、概念模型、验收条目、ADR | 关键未知项有明确处置 |
| 3：实施规划 | 独立业务实现方案与任务 | 获准进入业务代码阶段 |
| 4：实现及验证 | 后续 PR 中的业务代码与验证证据 | 满足届时已确认的验收标准 |

公开文档发布单独推进：内容审阅与合并、确认 Pages 来源为 GitHub Actions、部署工作流成功、访问项目子路径验证。配置存在并不等于已经上线。
