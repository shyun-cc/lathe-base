## 业务模型：待确认

仓库不存在 schema、实体定义或接口，因此当前不声明业务实体、字段、关系或数据库选型，也不输出建表 SQL。

确认首个业务场景后，按以下模板逐项讨论：

| 项目 | 需要补充的内容 |
| --- | --- |
| 概念名称 | 用户使用的业务术语及定义 |
| 标识与生命周期 | 如何区分对象，何时创建、结束或删除 |
| 关系 | 与其他概念的关系及数量约束 |
| 不变量 | 始终应满足的业务规则 |
| 数据边界 | 来源、敏感性、保留与访问要求 |

## 文档信息模型（提案）

一个场景可以关联多个验收条目；一个决策记录说明某项设计取舍及其影响；一个未决问题关闭时应链接到相应决策或已修订的场景。这只是文档组织关系，不是产品数据库。
