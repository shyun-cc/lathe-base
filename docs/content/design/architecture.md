## 文档基础设施（本轮配置）

`docs/content` Markdown → Hugo Extended + 固定版本 OINK 模块 → 静态站点产物 → GitHub Pages 工作流。

文档模块 `docs/go.mod` 独立存在；构建目录不纳入版本控制。公开地址配置为 GitHub 项目子路径 `/lathe-base/`。文档导航使用 Hugo `relref`，使生成链接保留子路径。
