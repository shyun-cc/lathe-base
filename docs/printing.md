# 打印与模板配置

在销售订单、生产工单或发货单详情中点击「打印预览」。选择内置模板或已发布的实例模板，检查表头、明细和表底内容，再点击「打印 / 保存 PDF」。浏览器可选择打印机或另存 PDF。建议在浏览器打印窗口关闭网页页眉和页脚，并核对模板纸张和实际纸盒类型。

## 配置模板

1. 打开「配置 → 打印模板」，选择销售单、工单或送货单。可以从内置配置开始，也可以打开历史版本编辑。
2. 填写模板编号、名称和打印标题，选择 A4 或 A5、纵向或横向及每行的栏数。
3. 表头和表底栏可选择单据字段，也可填写固定文字。仅填写标签会留出签名线。通过占栏数和上移、下移调整版面。
4. 明细列可设置字段、标题、相对宽度和对齐方式。例如相邻列设为 2 和 1，前者分配到两倍宽度。
5. 确认样例预览后，点击「保存新版本」再点击「发布此版本」。同一单据类别和模板编号只保留一个生效版本。可重新发布历史版本来恢复旧版，生效模板在单据预览时可选择。

## 编辑 JSON

「编辑 JSON」显示当前配置，可以复制备份或粘贴配置。修改后先点击「应用到表单」，检查预览，随后保存和发布。字段键可从同类内置模板的 JSON 中查找，单位和日期数据来自对应单据。下面是送货单示例。

```json
{
  "title": "送货单",
  "paper": "A5",
  "orientation": "landscape",
  "columnsPerRow": 2,
  "header": [
    { "label": "送货单号", "field": "number", "text": "", "span": 1 },
    { "label": "客户", "field": "party", "text": "", "span": 1 }
  ],
  "columns": [
    { "label": "物料", "field": "product", "width": 2, "align": "left" },
    { "label": "数量", "field": "quantity", "width": 1, "align": "right" }
  ],
  "footer": [
    { "label": "收货签字", "field": "", "text": "", "span": 2 }
  ]
}
```

表头和表底栏各可配置 24 项，明细可配置 1 至 12 列。导入时请使用对应单据类别支持的字段。
